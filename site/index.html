Install

Install the Chrome extension from its ZIP.

This release is not in the Chrome Web Store. Chrome calls this an unpacked extension.

  1. 1

    Download and unzip

    Download the ZIP, then extract it to a folder you can keep.

  2. 2

    Open Chrome extensions

    Enter chrome://extensions in Chrome. Turn on Developer mode.

  3. 3

    Load the folder

    Select “Load unpacked,” then choose the extracted folder containing manifest.json.

Download extension ZIP

How it works

From captions to one readable page.

  1. 01

    Open a captioned talk

    Visit a YouTube or TED video whose captions or transcript you can already access.

  2. 02

    Tidy the transcript

    Select the extension. It reads the available caption track and reflows fragments locally.

  3. 03

    Read your way

    Search, change type and spacing, jump to any moment, print, or export the full text.

Privacy

Transcript text stays in your browser.

Transcript Tidy reads caption tracks only when you select it on an open source page. It does not download video, create missing transcripts, track reading, or publish a transcript library.
